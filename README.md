# CyberSafe AI - GPU Accelerated Threat Detection

CyberSafe AI is a cybersecurity threat detection platform designed to identify and analyze potential security threats using feature-based risk analysis and AI-oriented security monitoring.

## Features

- Phishing and malicious URL detection
- Malware file analysis
- Network intrusion detection
- Explainable threat analysis
- Threat risk scoring
- GPU/TensorRT-oriented monitoring
- Cyber threat visualization dashboard

## Technologies Used

- HTML
- CSS
- JavaScript
- Python
- NVIDIA GPU / TensorRT concepts
- Canvas API
- Cybersecurity threat analysis

## Project Modules

### URL Scanner
Analyzes URLs using features such as:
- Domain entropy
- Suspicious keywords
- High-risk TLDs
- IP address usage
- Subdomain count
- HTTP/HTTPS protocol

### Malware Scanner
Analyzes executable files using file characteristics and suspicious API indicators.

### Network Intrusion Detection
Displays and analyzes network events such as DDoS, DNS tunneling, SSH brute force and SQL injection activity.

### GPU Monitoring
Provides GPU-oriented performance and inference monitoring using FP16 and INT8 concepts.

## Project Structure

- `index.html` – Main dashboard
- `styles.css` – User interface styling
- `app.js` – Application logic
- `ai_models.js` – Threat analysis and risk scoring
- `server.py` – Python server/backend
- `gpu_benchmark.js` – GPU performance monitoring
- `threat_map.js` – Threat visualization

## Objective

The objective of CyberSafe AI is to provide a centralized cybersecurity platform that helps users identify suspicious URLs, malware indicators and network threats through an interactive dashboard.
